# AI together

一个 Windows 桌面端「AI 群聊」应用：创建一个群，拉多个 AI 成员进群，@谁谁回复——像微信群一样和多家大模型同时聊天。

## 功能

- 🏠 **多群聊**：可建多个群，每个群独立话题、独立成员
- 👥 **多 AI 成员**：OpenAI 兼容（DeepSeek / Kimi / 豆包 / MiniMax / 智谱 / Ollama 等）、Anthropic、Gemini 三类接口都能接，可自由设置人设和系统提示词
- 💬 **@提及触发**：@谁谁回，不@不打扰；被@的多个成员会依次接话，互相看得到彼此的发言
- 🧭 **智能路由**：mention_only / all / smart 三种模式，smart 下由路由器自动挑选该谁接话
- ⏳ **队列与流式**：回复逐字流出，排队状态可见，随时可一键停止
- 🔍 **联网搜索**：接入 Tavily 等搜索服务，成员可自主调用 `web_search`，回复附来源列表；消息以「搜索：xxx」开头可强制先搜再答
- 🔌 **MCP 工具**：接入 MCP（Model Context Protocol）服务器，让成员能调用外部工具。逐工具授权、必须填写用途说明、服务器改动工具会自动失效授权
- 🧠 **群记忆**：群聊变长后早期结论会被上下文裁掉，可一键生成摘要沉淀下来；摘要按外部数据对待，其中的指令不会被执行
- 📎 **附件**：选取文本文件随消息发送，内容仅注入本轮，不写入数据库
- 🌗 **深色主题**：浅色 / 深色 / 跟随系统
- 🔒 **本地存储**：聊天记录和 API Key 都只存在你自己电脑的 SQLite 里

## 下载安装

在 [Releases](https://github.com/xlc0007/ai-together/releases/latest) 页面下载最新的 `AI-groupchat_0.5.0_x64-setup.exe`，双击安装（简体中文界面，自动安装 WebView2 运行时，无需管理员权限）。

> 早期版本也可在下方文件列表点击 `AI群聊_0.1.1_x64-setup.exe` → 右上角 **Download raw file**。

## 使用步骤

1. 打开应用 →「成员管理」→ 新建成员
2. 选择厂商预设（或手填接口地址），粘贴你自己的 API Key
3. 点「⟳ 获取模型列表」直接选择可用模型 → 测试连接
4. 回到群聊，@他 发消息即可

> API Key 需自行到各厂商开放平台申请；Key 仅保存在本地，不会上传。

### 想用 MCP 工具？

1. 「设置」→「AI 工具总开关」勾选启用
2. 同页「MCP 服务器」填入服务器地址（仅支持 Streamable HTTP，如 `https://mcp.deepwiki.com/mcp`）
3. 点「工具授权」→ 勾选要用的工具 → 每个都要填一句用途说明 → 保存
4. 到「成员管理」给对应成员勾选「允许 MCP 工具」

> 注意：不支持 stdio（`npx xxx`）型和需要 OAuth 登录的服务器；工具参数只支持文本/数字/布尔，参数结构复杂的工具会被自动禁用（设置页会标注）。

### 群聊变长、成员开始忘事？

「群管理」→ 选中当前群 → 点「记忆」：

1. 选一个成员当总结者（默认第一个启用的）
2. 点「生成本群记忆」，确认弹窗会告诉你将发送多少条消息给哪个模型
3. 生成后，之后每轮对话都会附带这份摘要

摘要只记录已确认的事实与结论，不记过程。它由模型生成、可能有误，注入时按外部数据对待——摘要里出现的任何「指令」都不会被执行。建议每 50 条消息左右更新一次。
